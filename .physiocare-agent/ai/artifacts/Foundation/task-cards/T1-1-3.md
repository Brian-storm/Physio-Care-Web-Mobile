## 目標

建立並驗證 Docker Compose 開發環境，同時運行前端（Next.js :3000 → host :3001）與後端（FastAPI :8000 → host :8001），並支援 hot-reload。

## 情境包（Context Pack）

- 相關檔案：
  - `docker-compose.yml`
  - `backend/Dockerfile`
  - `frontend/Dockerfile`
  - `backend/.dockerignore`
  - `frontend/.dockerignore`
- 既有模式：
  - Docker Compose 已設定 `version: '3.9'`
  - backend service: build `./backend`, port mapping `8001:8000`, `--reload` flag 啟用
  - frontend service: build `./frontend`, port mapping `3001:3000`, `npm run dev`
  - backend volume mount `./backend:/app` 支援 hot-reload
  - frontend volume mounts: `./frontend:/app`, `/app/node_modules` (anonymous), `/app/.next` (anonymous)
  - 後端環境變數 `DATABASE_URL=sqlite:///./physiocare.db`
  - 前端環境變數 `NEXT_PUBLIC_API_URL=http://localhost:8001`
  - `backend_data` named volume 用於持久化 SQLite 資料
- 假設：
  - Docker Desktop 已安裝
  - 本地 port 3001 與 8001 未被佔用
- 未知事項：
  - Windows 與 Linux 的 volume mount 效能差異
- 允許變更的檔案：
  - `docker-compose.yml`
  - `backend/Dockerfile`
  - `frontend/Dockerfile`
  - `.dockerignore` 檔案
- 不得觸碰：
  - 應用程式原始碼（`frontend/src/`、`backend/app/`）

## 需求

- `docker compose build` 可成功 build 兩個 image
- `docker compose up` 可同時啟動 backend（:8001）與 frontend（:3001）
- Backend hot-reload 正常（修改 Python 檔案後自動重啟）
- Frontend hot-reload 正常（修改 TypeScript 檔案後自動更新）
- 前端可透過 `http://localhost:8001` 呼叫後端 API（跨域）
- 兩個 container 的名稱分別為 `physiocare-backend` 與 `physiocare-frontend`

## 驗收標準

- `docker compose build` 成功，無 error
- `docker compose up -d` 後 `docker compose ps` 顯示兩個 service 皆為 `Up`
- `curl http://localhost:8001/health` 回傳 200
- `curl http://localhost:3001` 回傳 Next.js HTML
- 修改 `backend/app/main.py` 後後端自動重啟
- 修改 `frontend/src/app/page.tsx` 後前端自動更新

## 實作備註

- `NEXT_PUBLIC_API_URL` 設為 `http://localhost:8001`（host port）因為前端在瀏覽器執行，需存取 host 上的 backend port
- 若 port 衝突，調整 `docker-compose.yml` 中的 ports mapping
- Windows 使用者注意：volume mount 效能可能較慢，`WSL2` backend 建議啟用
