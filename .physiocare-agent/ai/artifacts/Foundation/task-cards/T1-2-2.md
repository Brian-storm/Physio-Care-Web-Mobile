## 目標

建立 Python seed 腳本，在資料庫初始化時自動寫入標準運動目錄資料，包含「Squat」以及其他 2-3 個常見復健運動（如 "Straight Leg Raise", "Clam Shell", "Wall Push-up"）。腳本可獨立執行，也可整合至 FastAPI startup event。

## 需求

- 建立 `backend/app/core/seed.py`，包含 `seed_exercises(session: Session)` function
- 該 function 在 `exercise` 表為空時插入預設運動資料
- 至少包含以下運動：
  1. **Squat**
     - category: "lower_body"
     - description: "Stand with feet shoulder-width apart, bend knees and lower hips as if sitting in a chair"
     - target_sets: 3, target_reps: 12
     - safety: max_knee_valgus=0.08, min_hip_angle=60, max_back_arch=40, max_pain_score=7
  2. **Straight Leg Raise**
     - category: "lower_body"
     - description: "Lying on back, one leg straight, lift to 45 degrees keeping knee locked"
     - target_sets: 3, target_reps: 10
     - safety: max_knee_valgus=0.05, min_hip_angle=30, max_back_arch=20, max_pain_score=5
  3. **Clam Shell**
     - category: "lower_body"
     - description: "Lying on side with knees bent at 45 degrees, lift top knee while keeping feet together"
     - target_sets: 3, target_reps: 12
     - safety: max_knee_valgus=0.1, min_hip_angle=20, max_back_arch=30, max_pain_score=6
- 在 `backend/app/main.py` 的 `on_startup` event 中呼叫 `seed_exercises`
- 支援獨立執行：`python -m app.core.seed`

## 驗收標準

- `python -c "from app.core.seed import seed_exercises; from app.core.database import engine; from sqlmodel import Session; with Session(engine) as s: seed_exercises(s); s.commit()"` 執行後 exercise 表有 3 筆資料
- 重複執行不會產生重複資料
- FastAPI 啟動日誌顯示 "Seeded X exercises"
- 使用 SQLite CLI 查詢 `.tables` 與 `SELECT * FROM exercise` 確認資料

## 實作備註

- 使用 `session.exec(select(Exercise)).first() is None` 判斷是否需要 seed
- 所有運動的 `id` 使用 UUID 自動生成
- 可考慮將 seed 資料以 list of dict 定義，方便未來擴充
