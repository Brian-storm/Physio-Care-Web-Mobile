## 目標

在 FastAPI 中新增 `GET /api/v1/exercises` 端點，回傳運動目錄中的所有 Exercise 資料。同時可選地支援 `GET /api/v1/exercises/{exercise_id}` 單筆查詢。前端可透過此端點取得可用的運動列表。

  - `backend/app/api/endpoints.py`

- 既有模式：
  - Endpoints 使用 `router = APIRouter(prefix="/api/v1", tags=["patients"])`

## 需求

- 新增 `GET /api/v1/exercises` 端點，回傳 `list[ExerciseResponse]`
- 新增 `GET /api/v1/exercises/{exercise_id}` 端點，回傳單筆 `ExerciseResponse`，不存在時回傳 404
- 端點 tag 使用 `"exercises"`
- 使用 `from app.models.models import Exercise` 進行查詢
- 使用 `from app.schemas.schemas import ExerciseResponse` 作為 response_model

## 驗收標準

- `curl http://localhost:8000/api/v1/exercises` 回傳 200 + JSON array
- `curl http://localhost:8000/api/v1/exercises/{id}` 回傳單筆資料
- `curl http://localhost:8000/api/v1/exercises/nonexistent-id` 回傳 404
- Swagger UI `/docs` 中顯示新的 endpoints

## 實作備註

- 由於 `Exercise` 是新 model，注意 router prefix 與現有 endpoints 的 tag 命名一致
- 可考慮將 router 拆分為多個檔案（如 `patients.py`, `exercises.py`）但本期先維持單一檔案
