## 需求

- **PageHeader** (`frontend/src/components/layout/PageHeader.tsx`):
  - Props: `title`, `subtitle?`, `actions?` (ReactNode for buttons), `className?`
  - 固定高度（~56-64px），底部 border
  - 左側 title + subtitle，右側 actions slot
  - 支援 responsive（mobile 時隱藏 subtitle）
- **Sidebar** (`frontend/src/components/layout/Sidebar.tsx`):
  - Props: `items` (NavItem[]), `activeItem?`, `onItemClick?`, `collapsed?`, `className?`
  - NavItem interface: `{ id: string, label: string, icon?: ReactNode, href?: string }`
  - 預設展開寬度 ~256px（w-64），收起寬度 ~64px（w-16）
  - 支援 collapsed/expanded 切換（內建 toggle button）
  - 底部顯示應用名稱與版本
  - 使用 Badge 元件顯示未讀通知數量
- **DashboardLayout** (`frontend/src/components/layout/DashboardLayout.tsx`):
  - Props: `sidebar`, `header?`, `children`, `className?`
  - 使用 CSS Grid 或 flex 劃分：header (fixed top) + sidebar (fixed left) + main content (scrollable)
  - Main content 區域 overflow-y-auto
  - 支援 sidebar collapsed/expanded 狀態管理
  - 響應式設計：mobile 時 sidebar 變 overlay drawer
- 所有元件使用 TypeScript interface 定義 props，named export
- 每個元件檔案包含 JSDoc 註解
