## 目標

建立 FastAPI 後端專案，包含 SQLModel ORM、SQLite 資料庫、Pydantic schemas、CORS 設定、健康檢查端點。使用 `app/` 套件結構分層：`core/`（config, database）、`models/`（SQLModel tables）、`schemas/`（Pydantic）、`api/`（endpoints）。

## 情境包（Context Pack）

- 相關檔案：
  - `backend/app/main.py`
  - `backend/app/core/config.py`
  - `backend/app/core/database.py`
  - `backend/app/models/models.py`
  - `backend/app/schemas/schemas.py`
  - `backend/app/api/endpoints.py`
  - `backend/requirements.txt`
  - `backend/pyproject.toml`
  - `backend/Dockerfile`
  - `backend/.env`
- 既有模式：
  - 使用 FastAPI + SQLModel（非 SQLAlchemy 直用）
  - `Settings` 類別使用 `pydantic-settings` 讀取 `.env`
  - `init_db()` 在 startup event 呼叫 `SQLModel.metadata.create_all(engine)`
  - `get_session()` 作為 FastAPI Depends 注入
  - SQLite 使用 `check_same_thread=False`
  - CORS 白名單預設 `http://localhost:3000`
  - 已有 Patient, PrescribedExercise, SessionRecord, FlaggedClip 四個模型
  - 已有對應的 CRUD endpoints（patients, exercises, sessions, progress）
- 假設：
  - Python 3.11+ 已安裝
  - 使用 SQLite 作為開發資料庫，後續才遷移至 Supabase PostgreSQL
- 未知事項：
  - 尚無 Alembic migration 設定（SQLite 開發階段使用 `create_all`）
- 允許變更的檔案：
  - 任何 `backend/` 下的檔案（若需要修正既有設定）
- 不得觸碰：
  - `frontend/` 目錄
  - Docker Compose 設定

## 需求

- 確保 FastAPI 應用可正常啟動於 `localhost:8000`
- 確保 `/health` 回傳 `{"status": "ok", "app": "PhysioCare API"}`
- 確保 startup 時自動建立所有資料表
- 確保 CORS middleware 正確設定
- 確保 `GET /docs` 可開啟 Swagger UI
- 確保 `uvicorn app.main:app --reload` 可正常運作

## 驗收標準

- `cd backend && pip install -r requirements.txt && uvicorn app.main:app --reload` 啟動成功

- `curl http://localhost:8000/docs` 回傳 Swagger HTML
- `python -c "from app.main import app; print('OK')"` 無錯誤
