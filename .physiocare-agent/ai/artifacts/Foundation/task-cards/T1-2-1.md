## 目標

在 SQLModel 中定義一個獨立於 patient 的 `Exercise` 資料表，存放可供參考的標準化運動項目（如 "Squat", "Lunges", "Push-ups"），包含運動名稱、描述、預設安全參數與臨床目標。此模型與 `PrescribedExercise`（已綁定 patient）不同，屬於運動目錄（exercise catalog）。

## 情境包（Context Pack）

- 相關檔案：
  - `backend/app/models/models.py`
  - `backend/app/schemas/schemas.py`
- 既有模式：
  - 現有 SQLModel 都使用 `uuid` 作為 primary key，`default_factory=lambda: str(uuid.uuid4())`
  - 使用 `Field(default_factory=datetime.utcnow)` 記錄時間戳
  - Schema 檔案使用 Pydantic `BaseModel` 定義 request/response
  - 現有 `PrescribedExercise` 已包含安全參數（safety_max_knee_valgus, safety_min_hip_angle 等）
- 假設：
  - `Exercise` 模型作為運動目錄，不與特定 patient 綁定
  - 安全參數以運動本身預設值存在，允許 PrescribedExercise 覆寫
- 未知事項：
  - 是否需要 `category` 欄位（如 "lower_body", "upper_body", "core"）
- 允許變更的檔案：
  - `backend/app/models/models.py`（新增 `Exercise` 類別）
  - `backend/app/schemas/schemas.py`（新增 `ExerciseResponse` 與 `ExerciseCreate` 通用版）
- 不得觸碰：
  - `backend/app/api/endpoints.py`（由 T1-2-3 處理）
  - `frontend/` 目錄

## 需求

- 在 `backend/app/models/models.py` 中新增 `Exercise` SQLModel（table=True）
- 欄位：
  - `id`: str, primary key, UUID
  - `name`: str, 運動名稱（如 "Squat"）
  - `description`: str, 文字描述
  - `category`: str, 分類（"lower_body", "upper_body", "core", "full_body"）
  - `clinical_goal`: str, 臨床目標
  - `target_sets`: int, default 3
  - `target_reps`: int, default 12
  - `safety_max_knee_valgus`: float, default 0.08
  - `safety_min_hip_angle`: float, default 60.0
  - `safety_max_back_arch`: float, default 40.0
  - `safety_max_pain_score`: int, default 7
  - `created_at`: datetime
- 在 `backend/app/schemas/schemas.py` 中新增 `ExerciseResponse` 與 `ExerciseCreate` schema
- 資料表名稱使用預設（`exercise`）
