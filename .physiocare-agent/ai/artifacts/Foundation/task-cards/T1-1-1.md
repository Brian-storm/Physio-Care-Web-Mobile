## 目標

建立 Next.js 14 前端專案，包含 TypeScript strict mode、TailwindCSS v3、PostCSS、ESLint、以及 `@/` path alias。同時設定 MediaPipe WASM 所需的 COOP/COEP headers，並建立基本的 root layout 與 globals.css。
