## 目標

在 TailwindCSS config 中定義完整的 design token 系統，包含色票（primary green, danger red, neutral gray, accent blue, warning yellow）、字型比例（type scale）、間距（spacing）、圓角（border radius）、陰影（shadow）、動畫（animation）等。確保所有 token 符合 medical/clinical 應用的視覺調性。

## 需求

- 在 `tailwind.config.js` 中擴充或新增以下 design tokens：
  - **Colors**:
    - `primary` (green) — 已存在，維持不變
    - `danger` (red) — 已存在，維持不變
    - `neutral` (slate/gray) — 使用 Tailwind 內建 `slate`
    - `success` (emerald) — 用於正向反饋
    - `warning` (amber/yellow) — 用於警告
    - `info` (blue) — 用於資訊提示
  - **Font family**: 維持系統字型堆疊（`Inter`, `system-ui`, `sans-serif`），可在 `globals.css` 中設定
  - **Border radius**: 擴充 `radius` 包含 `xs`, `sm`, `DEFAULT`, `lg`, `xl`, `2xl`
  - **Animation**: 新增 `fade-in`, `slide-up`, `scale-in` 等實用動畫
  - **Font size**: 確認 type scale 涵蓋 `xs` 到 `4xl`（使用 Tailwind 預設即可）
- 在 `globals.css` 中定義 CSS custom properties 供 Tailwind 參考：
  - `--color-primary-*`, `--color-danger-*` 等
- 確保 dark mode 使用 class-based strategy（`dark:` prefix）
