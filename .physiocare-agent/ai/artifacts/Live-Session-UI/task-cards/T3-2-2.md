## 目標

建立 `ExerciseTimer` 元件，提供運動階段的即時碼錶計時功能：顯示已花費時間（elapsed time），並可在 session 開始/結束時啟動與停止。此元件為純視覺計時器，不管理 session 生命週期（由 T3-3-1 useSession hook 負責）。

## 情境包（Context Pack）

- 相關檔案：`frontend/src/types/pose.ts`（ExerciseResult 有 duration 欄位）、無既有計時器實作
- 既有模式：新元件，無既有模式可參考。codebase 使用 `useRef` + `useState` 模式（例如 useCamera.ts 的 state management pattern）。
- 假設：計時器顯示格式為 `MM:SS`（如 `03:45`）。更新頻率為每秒一次（setInterval 1000ms）。
- 未知事項：是否支援暫停（pause/resume）功能。初期只實作 start/stop，暫停視為 stop。
- 允許變更的檔案：`frontend/src/components/ExerciseTimer.tsx`（新檔案）
- 不得觸碰：`frontend/src/app/page.tsx`、`frontend/src/types/pose.ts`

## 需求

- 接收 `isRunning: boolean` prop 控制計時器啟動／停止。
- 接收 `onTick?: (elapsedSeconds: number) => void` callback prop，每秒觸發一次回傳當前秒數（供父層記錄）。
- 內部使用 `useRef` 儲存 `startTime`（performance.now()）以確保精確度，不使用累加方式。
- 使用 `useState` 儲存 `displayTime: string`（格式 `MM:SS`）供 render。
- 在 isRunning 從 false 變 true 時 reset 並啟動計時；從 true 變 false 時停止。
- 顯示一個圓形或藥丸形狀的 badge 組件，左側有 pulsing 紅點（錄製指示）與時間文字。
- 使用 TailwindCSS：`bg-slate-800/80` 背景、`text-green-400` 時間文字、`h-2 w-2 rounded-full bg-red-500 animate-pulse` 紅點。
- 匯出名稱：`ExerciseTimer`（named export）。
- 檔案 header 註解：`/* PhysioCare — Elapsed time display for active exercise sessions */`

## 驗收標準

- isRunning=true 時計時器開始計數，顯示格式 `MM:SS`。
- isRunning=false 時計時器凍結在最後時間。
- isRunning 從 false→true 時計時器 reset 為 `00:00` 重新開始。
- onTick 每秒被呼叫一次並傳入正確的 elapsed seconds。
- 紅點在 isRunning=true 時 pulsing 動畫顯示。
- 無 TypeScript 錯誤，無 lint 警告。

## 實作備註

- 使用 `useEffect` 管理 `setInterval`，在 cleanup 時 `clearInterval`。
- 使用 `useRef` 儲存 `intervalId` 與 `startTime`，避免不必要的 re-render。
- `useState` 只用於儲存格式化後的字串，儲存頻率每秒一次。
- 元件尺寸小巧（約 120px wide），適合放在 FeedbackPanel 頂部或 header 區。
