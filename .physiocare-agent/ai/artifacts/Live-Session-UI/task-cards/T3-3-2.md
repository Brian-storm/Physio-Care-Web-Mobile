## 目標

建立 `SessionSummary` 元件，在運動 session 完成後顯示 recap 畫面。展示本次 session 的彙整數據：持續時間、完成 reps/sets、平均形式分數、最大危險分數、是否被標記，以及一個「儲存與關閉」按鈕。此元件透過 modal 或 overlay 顯示在 CameraView 上方。

## 情境包（Context Pack）

- 相關檔案：`frontend/src/hooks/useSession.ts`（T3-3-1，產出 SessionSummary 型別）、`frontend/src/types/pose.ts`（ExerciseResult 型別）、`frontend/src/components/FeedbackPanel.tsx`（T3-2-1，色票與設計語言參考）
- 既有模式：page.tsx 的 side panel 使用 `bg-slate-800/50`、`bg-slate-900`、`rounded-xl`、`shadow-2xl` 等 TailwindCSS 類別。SessionSummary 應延續相同設計語言。
- 假設：SessionSummary 作為 modal overlay 顯示在 CameraView 容器上方（absolute inset-0 z-50）。儲存邏輯由父層處理（T3-3-3）。
- 未知事項：是否支援重新開始（start another session）或關閉後回到 idle 狀態。初期實作「儲存與關閉」按鈕（呼叫 onSave callback）與「再來一輪」按鈕（呼叫 onRestart callback）。
- 允許變更的檔案：`frontend/src/components/SessionSummary.tsx`（新檔案）
- 不得觸碰：`frontend/src/hooks/useSession.ts`、`frontend/src/types/pose.ts`、`backend/app/`

## 需求

- 接收 `summary: SessionSummary | null` prop（來自 useSession）。
- 接收 `onSave: () => void` callback prop（儲存按鈕點擊時觸發）。
- 接收 `onRestart: () => void` callback prop（重新開始按鈕點擊時觸發）。
- 當 `summary === null` 時元件不渲染任何內容（回傳 null）。
- 顯示區塊（由上到下）：
  1. **Header**：`Session Complete` 標題 + 綠色 checkmark icon。
  2. **Duration**：顯示 `{durationSeconds}` 格式化為 `Xm Ys`。
  3. **Reps / Sets**：`{totalReps} reps`、`{totalSets} sets`。
  4. **Form Score**：`{avgFormScore}%`，顏色 green yellow red。
  5. **Danger Score**：`{maxDangerScore}%`，顏色 green yellow red。
  6. **Flagged Badge**：如 flagged 為 true 顯示紅色 badge「Flagged — Review recommended」。
  7. **按鈕**：`Save & Close`（主要按鈕，強調樣式）與 `Start Another`（次要按鈕，文字樣式）。
- Modal overlay 樣式：`fixed inset-0 z-50 flex items-center justify-center bg-black/60 backdrop-blur-sm`。
- Modal 卡片樣式：`bg-slate-900 border border-slate-700 rounded-2xl shadow-2xl p-8 max-w-sm w-full mx-4`。
- 按鈕樣式：主要按鈕 `bg-green-600 hover:bg-green-700 text-white font-medium rounded-lg px-6 py-2.5`，次要按鈕 `text-slate-400 hover:text-white underline underline-offset-2`。
- 匯出名稱：`SessionSummary`（named export）。
- 檔案 header 註解：`/* PhysioCare — Post-session recap modal with summary data, save, and restart options */`

## 驗收標準

- summary 為 null 時元件不渲染任何 DOM 節點。
- summary 有值時顯示 modal overlay 與所有數據區塊。
- 點擊「Save & Close」觸發 onSave callback。
- 點擊「Start Another」觸發 onRestart callback。
- Flagged 為 true 時顯示 flagged badge，false 時隱藏。
- 所有數值正確對應 summary props。
- 無 TypeScript 錯誤，無 lint 警告。
