## 需求

- 接收 `state: ExerciseState` prop。
- 顯示區塊：
  1. **Header**：運動名稱（state.exercise）+ 階段文字（state.phase，依 PHASE_LABELS 對應，顏色依 POSE_COLORS）。
  2. **Rep/Set 計數器**：兩個並排卡片顯示 state.repCount / state.targetReps 與 state.setCount / state.targetSets。
  3. **Joint Angles**：state.angles 陣列的每項顯示名稱 + 數值 + 進度條（綠色 for target、紅色 for under/over）。
  4. **Form Score**：顯示 state.formScore%，顏色 green（>=80）、yellow（>=50）、red（<50）。
  5. **Danger Score**：顯示 state.dangerScore%，顏色 green（<25）、yellow（<50）、red（>=50）。
  6. **Flagged Alert**：state.isFlagged 為 true 時顯示紅色 pulsing 警示文字。
  7. **Correction Cues**：空的 `cues: string[]` section（預留，顯示「No corrections needed」或隱藏）。
- 使用 TailwindCSS 樣式，色票沿用 page.tsx side panel 的 `bg-slate-800/50`、`bg-slate-700/50`、`border-slate-700`、文字色 `text-slate-400`、`text-slate-500` 等。
- 匯出名稱：`FeedbackPanel`（named export）。
- 檔案 header 註解：`/* PhysioCare — Real-time feedback panel: scores, joint angles, correction cues */`
