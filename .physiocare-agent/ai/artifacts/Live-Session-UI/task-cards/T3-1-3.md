## 目標

在 `PoseCanvas` 元件的 skeleton overlay 上，於膝關節（hip-knee-ankle）、髖關節（shoulder-hip-knee）、軀幹 lean（shoulder-hip 垂直角）處標註即時角度數值，讓使用者直觀看到自己的關節角度。

## 情境包（Context Pack）

- 相關檔案：`frontend/src/components/PoseCanvas.tsx`（T3-1-1 產出物）、`frontend/src/utils/angles.ts`（calculateKneeAngle, calculateHipAngle, calculateTorsoAngle）、`frontend/src/app/page.tsx:124-152`（現有角度標籤繪製邏輯）
- 既有模式：page.tsx 的 drawSkeleton 已在膝 (+10, +5)、髖 (+10, -10)、肩 (+10, -20) 處繪製角度標籤，使用 `ctx.strokeText + ctx.fillText` 疊加產生文字外框效果。
- 假設：角度標籤永遠在 canvas 座標空間中，不受 video 縮放影響。文字使用 `bold 14px monospace`，白字黑框。
- 未知事項：未來是否支援其他運動（如 shoulder press 需要手肘角度）。暫只實作 squat 所需的三個角度（膝、髖、軀幹），骨架作為參數可擴充。
- 允許變更的檔案：`frontend/src/components/PoseCanvas.tsx`（在 T3-1-1 基礎上增加角度繪製邏輯）
- 不得觸碰：`frontend/src/utils/angles.ts`、`frontend/src/types/pose.ts`、`frontend/src/app/page.tsx`

## 需求

- 當 PoseCanvas 的 `showAngles` prop 為 true 時，在下列位置繪製角度標籤：
  - 膝關節偏移 (+10px x, +5px y) 顯示 `{kneeAngle}°`
  - 髖關節偏移 (+10px x, -10px y) 顯示 `{hipAngle}°`
  - 肩關節偏移 (+10px x, -20px y) 顯示 `Torso {torsoAngle}°`
- 角度值使用 `Math.round()` 取整數，不顯示小數點。
- 使用 `ctx.font = 'bold 14px monospace'`、`ctx.fillStyle = '#ffffff'`、`ctx.strokeStyle = '#000000'`、`ctx.lineWidth = 3`。
- 中點計算：膝 = left/right knee 平均、髖 = left/right hip 平均、肩 = left/right shoulder 平均（沿用 page.tsx 的 KEY_LANDMARKS 邏輯）。
- 當 `showAngles` 為 false 或 landmarks 不足時不繪製角度標籤。
- 所有角度計算使用 `calculateKneeAngle`、`calculateHipAngle`、`calculateTorsoAngle`。

## 驗收標準

- showAngles=true 時，canvas 上顯示三個角度標籤（膝、髖、軀幹）。
- 角度值與 `utils/angles.ts` 的計算結果一致。
- 標籤位置正確對應關節中點。
- showAngles=false 時標籤不顯示。
- 無 TypeScript 錯誤，無 lint 警告。
