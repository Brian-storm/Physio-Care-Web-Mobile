## 目標

建立 `useSession` React hook，管理運動 session 的生命週期：狀態（idle / active / completed）、開始／停止動作、經過時間追蹤、以及收集 session summary 資料。此 hook 為 FeedbackPanel（T3-2-1）與 ExerciseTimer（T3-2-2）的上層邏輯提供者。

## 需求

- 回傳物件：
  ```ts
  {
    status: 'idle' | 'active' | 'completed';
    elapsedSeconds: number;
    startSession: () => void;
    stopSession: () => void;
    summary: SessionSummary | null;
  }
  ```
- `SessionSummary` 型別（定義在 hook 內或 `types/pose.ts`）：
  ```ts
  interface SessionSummary {
    durationSeconds: number;
    totalReps: number;
    totalSets: number;
    avgFormScore: number;
    maxDangerScore: number;
    flagged: boolean;
  }
  ```
- `startSession()`：將 status 設為 `active`，記錄 startTime，重置 summary 收集數據。
- `stopSession()`：將 status 設為 `completed`，計算 duration，凍結 summary。
- 接收一個 `onTick?: (elapsed: number) => void` callback（每秒觸發，由父層傳入 ExerciseTimer 行為需要）。
- **不直接**管理計時器 UI（由 ExerciseTimer 負責）。hook 只提供 elapsedSeconds 狀態與 start/stop 控制。
- 使用 `useRef` 儲存 startTime 以避免不必要 re-render；使用 `useState` 儲存 status 與 summary。
- 使用 `useEffect` 在 active 時啟動 `setInterval` 每秒更新 elapsedSeconds。
- 提供 `updateStats(currentState: ExerciseState): void` 方法讓父層在 animation loop 中呼叫以累計 reps/sets/scores。
- 檔案 header 註解：`/* PhysioCare — React hook for exercise session lifecycle: start, stop, duration, summary */`

## 驗收標準

- 初始 status 為 `idle`，elapsedSeconds 為 0，summary 為 null。
- 呼叫 `startSession()` 後 status 變為 `active`，elapsedSeconds 開始增加。
- 呼叫 `stopSession()` 後 status 變為 `completed`，duration 凍結，summary 不為 null。
- 在 active 期間呼叫 `updateStats()` 會正確累計 reps/sets 並更新 avgFormScore / maxDangerScore。
- 多次 start→stop 循環正確 reset 狀態。
- 無 TypeScript 錯誤，無 lint 警告。

## 實作備註

- avgFormScore 使用滾動平均（running average）方式累計：`avg = (avg * count + newValue) / (count + 1)`。
- maxDangerScore 使用 `Math.max` 累計。
- 不發送 API request（由 T3-3-3 負責）。
- 參考 useCamera 的 cleanup pattern（cleanup 時 clearInterval）。
