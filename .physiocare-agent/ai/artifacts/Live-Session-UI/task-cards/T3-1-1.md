## 目標

建立一個獨立的 `PoseCanvas` React 元件，接收 `Landmark[]` 陣列並在 `<canvas>` 上繪製人體骨架連線與關鍵點（keypoint dots）。此元件負責純渲染邏輯（no video, no detection），可被 `CameraView` 複用。

## 情境包（Context Pack）

- 相關檔案：`frontend/src/app/page.tsx:17-24`（SKELETON_CONNECTIONS 常數）、`frontend/src/app/page.tsx:83-155`（現有內聯 drawSkeleton 函式）、`frontend/src/types/pose.ts`（Landmark, LandmarkIndex）、`frontend/src/utils/angles.ts`（calculateKneeAngle, calculateHipAngle, calculateTorsoAngle）
- 既有模式：page.tsx 中已有一份內聯的 drawSkeleton 實作，使用 `SKELETON_CONNECTIONS` 畫線、畫關鍵點、並在髖／膝／肩處標註角度文字。需從中提取為獨立元件。
- 假設：canvas 尺寸從 video 解析度決定（透過 props 傳入 width/height 或 auto-resize）。顏色可暫用 page.tsx 現有值（綠色 #22c55e 骨架、白色文字、黑色 stroke 字框）。
- 未知事項：是否支援 skeleton connection 可設定（pros: 通用元件可被不同運動複用；cons: 初期只有 squat 一種骨架）。先寫死 squat 骨架並透過 props 接受 connections 陣列以保留彈性。
- 允許變更的檔案：`frontend/src/components/PoseCanvas.tsx`（新檔案）

## 需求

- 接收 `landmarks: Landmark[]` prop（33 點 MediaPipe 格式）。
- 接收 `width: number` 與 `height: number` prop 設定 canvas 解析度。
- 接收 `connections?: [number, number][]` prop 指定要繪製的連線（預設 squat 骨架連線）。
- 接收 `showAngles?: boolean` prop 控制是否在關節處標註角度（膝、髖、軀幹 lean）。
- 在 canvas 上繪製：骨架連線（綠線 3px）、關鍵點（綠色圓點半徑 4px，面部點 #94a3b8）、角度文字（白色 14px monospace bold + 黑色 stroke）。
- 當 `landmarks` 為空或長度不足時，清空 canvas 且不繪製任何內容（空狀態）。
- 使用 `useEffect` 在 props 變更時重繪 canvas。
- 回傳一個 React `forwardRef` 元件以允許父層取得 canvas DOM 節點（CameraView 合成 overlay 需要）。
- 匯出名稱：`PoseCanvas`（named export）。
- 檔案 header 註解：`/* PhysioCare — Canvas-based skeleton and landmark overlay renderer */`

## 驗收標準

- 給定 33 點 landmarks，canvas 上正確畫出骨架連線與關鍵點。
- `showAngles` 為 true 時，在膝、髖、肩處顯示角度標籤；false 時不顯示。
- 空 landmarks 陣列時 canvas 保持空白。
- 每次 props 變更（landmarks, width, height）後 canvas 重新繪製。
- forwardRef 正確暴露底層 `<canvas>` 元素。
- 無 TypeScript 錯誤，無 lint 警告。
