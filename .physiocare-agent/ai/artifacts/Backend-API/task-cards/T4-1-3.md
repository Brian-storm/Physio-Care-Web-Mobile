## Requirements

1. `PatientCreate` — request body for POST /patients
   - `name: str` (required)
   - If full model retained: `therapist_id: str`, `diagnosis: str = ""`, `goals: str = ""`
2. `PatientResponse` — response body for all patient endpoints
   - `id: str`, `name: str`, `created_at: datetime`
   - If full model retained: `therapist_id`, `diagnosis`, `goals`, `updated_at`
3. Both inherit from `pydantic.BaseModel`
