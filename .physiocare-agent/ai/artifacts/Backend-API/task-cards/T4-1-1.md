## 需求

1. 類別名稱為 `Patient`，繼承 `SQLModel` 並設定 `table=True`
2. 主鍵 id：型別 `str`，預設為 `uuid.uuid4()` 字串
3. name：`str`，不可為空
4. created_at：`datetime`，預設 `datetitime.ut cnow`

## 驗收標準

- Patient 模型匯入後無 ImportError
- `SQLModel.metadata.create_all(engine)` 在 SQLite 中成功建立 patient 表
- 可插入一筆 Patient(name="Test") 並寫入資料庫
