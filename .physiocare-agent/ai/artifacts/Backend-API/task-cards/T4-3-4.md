## Objective

Add an endpoint `GET /sessions/{session_id}/feedback` to retrieve all per-frame feedback records for a given session.

## Context Pack

- Relevant files: `backend/app/api/endpoints.py`, `backend/app/schemas/schemas.py`, `backend/app/models/models.py`
- Existing patterns: Similar to `GET /patients/{patient_id}/sessions` — filter by parent ID, return list.
- Assumptions: `Feedback` model exists (from T4-3-2). `FeedbackResponse` schema needs to be created.
- Unknowns: None.
- Allowed to modify: `backend/app/api/endpoints.py`, `backend/app/schemas/schemas.py`
- Do not touch: `backend/app/models/models.py`

## Requirements

1. `GET /sessions/{session_id}/feedback` — return all feedback records for a session
   - `response_model=list[FeedbackResponse]`
   - Ordered by `timestamp` ascending
   - Return 404 if session does not exist

## Acceptance Criteria

- `GET /sessions/{id}/feedback` returns `[]` when no feedback exists
- After inserting Feedback records, endpoint returns them ordered by timestamp
- Invalid session_id returns 404
- Each entry contains: `id`, `session_id`, `timestamp`, `angle_data`, `cues`, `frame_score`

## Implementation Notes

- Use `select(Feedback).where(Feedback.session_id == session_id).order_by(Feedback.timestamp)`
- Create `FeedbackResponse` schema in schemas.py inheriting from BaseModel
- Verify session exists before querying feedback (return 404 if missing)
