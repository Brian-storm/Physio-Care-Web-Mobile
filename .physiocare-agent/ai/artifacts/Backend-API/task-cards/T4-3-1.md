## Requirements

1. Class name `Session`, extends `SQLModel, table=True`
2. `id: str` — primary key, default uuid4
3. `patient_id: str` — foreign key to `patient.id`
4. `exercise_id: str` — foreign key to `exercise.id` (or `prescribedexercise.id`)
5. `score: float` — overall form score for the session
6. `duration: int` — duration in seconds
7. `started_at: datetime` — default `datetime.utcnow`
