## Objective

Create a `conftest.py` and test infrastructure in `backend/tests/` with pytest fixtures for an isolated test database, session dependency override, and reusable model factory fixtures.

## Context Pack

- Relevant files: `backend/tests/` (directory does not exist — create it), `backend/app/core/database.py`, `backend/app/models/models.py`, `backend/pyproject.toml` (pytest and pytest-asyncio in dev dependencies)
- Existing patterns: No existing test infrastructure. Database uses `engine` from `database.py` with SQLite. Need to override with in-memory SQLite for tests.
- Assumptions: pytest config is defined in pyproject.toml (or setup.cfg). No `__init__.py` needed in tests/ (namespace package).

## Requirements

1. Create `backend/tests/` directory
2. Create `backend/tests/conftest.py` with:
   - `db_engine` fixture: creates in-memory SQLite engine, creates all tables, drops after test
   - `db_session` fixture: yields a Session bound to the test engine
   - `client` fixture: FastAPI TestClient with `get_session` overridden to use `db_session`
   - `patient_factory` fixture: creates and returns a persisted Patient record
   - `exercise_factory` fixture: creates and returns a persisted Exercise record
   - `session_factory` fixture: creates and returns a persisted Session record
3. Ensure TestClient is properly configured with dependency override

## Acceptance Criteria

- `pytest --collect-only` discovers fixtures without errors
- Test using `client` fixture can call GET /patients
- `patient_factory` returns a Patient with a valid id and name
- Each test run uses a clean database (no data leakage between tests)

## Implementation Notes

- Use `from fastapi.testclient import TestClient`
- In-memory SQLite: `engine = create_engine("sqlite://", connect_args={"check_same_thread": False})`
- Dependency override pattern:
  ```python
  app.dependency_overrides[get_session] = lambda: db_session
  ```
- Import app from `app.main` — beware of circular imports; TestClient can be created in fixture
- Check if `__init__.py` is needed in tests/ by confirming pytest discovery works
