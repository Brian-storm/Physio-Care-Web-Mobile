## Objective

Add two read-only exercise endpoints in `backend/app/api/endpoints.py`: list all exercises and get a single exercise by ID.

## Context Pack

- Relevant files: `backend/app/api/endpoints.py` (has similar patterns for patient endpoints), `backend/app/schemas/schemas.py`, `backend/app/models/models.py`

- Assumptions: An `ExerciseResponse` schema exists or needs to be created. Note: an `ExerciseResponse` schema already exists but maps to `PrescribedExercise`. A new `ExerciseResponse` (or rename existing) may be needed for the standalone `Exercise` model.

- Allowed to modify: `backend/app/api/endpoints.py`, `backend/app/schemas/schemas.py`

## Requirements

1. `GET /exercises` — return list of all Exercise records, `response_model=list[ExerciseResponse]`
2. `GET /exercises/{exercise_id}` — return single Exercise, 404 if not found
3. Create `ExerciseResponse` and optionally `ExerciseCreate` schemas in schemas.py

## Acceptance Criteria

- `curl http://localhost:8000/exercises` returns `[]` when empty
- After inserting a Squat exercise directly, `GET /exercises/{id}` returns it with form_rules
- Invalid ID returns `{"detail": "Exercise not found"}` with 404
