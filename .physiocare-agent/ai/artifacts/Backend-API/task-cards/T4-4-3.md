## Requirements

1. Create test file(s) under `backend/tests/` covering:

   **Patient CRUD (T4-1-2)**
   - `test_create_patient`: POST /patients with valid data returns 201 + correct fields
   - `test_create_patient_missing_name`: POST /patients without name returns 422
   - `test_list_patients_empty`: GET /patients returns []
   - `test_list_patients_with_data`: GET /patients returns all created patients
   - `test_get_patient`: GET /patients/{id} returns patient
   - `test_get_patient_not_found`: GET /patients/{bad_id} returns 404

   **Exercise CRUD (T4-2-2)**
   - `test_list_exercises_empty`: GET /exercises returns []
   - `test_list_exercises_with_data`: GET /exercises returns exercises
   - `test_get_exercise`: GET /exercises/{id} returns exercise
   - `test_get_exercise_not_found`: GET /exercises/{bad_id} returns 404

   **Session CRUD (T4-3-3)**
   - `test_create_session`: POST /sessions with valid references returns 201
   - `test_create_session_invalid_patient`: returns 404
   - `test_list_sessions_empty`: GET /sessions returns []
   - `test_list_sessions_with_data`: returns sessions
   - `test_list_sessions_filter_by_patient`: GET /sessions?patient_id={id} filters

   **Session Feedback (T4-3-4)**
   - `test_get_feedback_empty`: GET /sessions/{id}/feedback returns []
   - `test_get_feedback_with_data`: returns feedback ordered by timestamp
   - `test_get_feedback_session_not_found`: returns 404

2. Run `pytest -v` and confirm all tests pass
