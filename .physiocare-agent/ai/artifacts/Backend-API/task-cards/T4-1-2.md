## 需求

1. `GET /patients` — 回傳所有 Patient 的 JSON 陣列，response_model=list[PatientResponse]
2. `GET /patients/{patient_id}` — 回傳單筆 Patient，不存在回 404
3. `POST /patients` — 接收 PatientCreate body，建立後回傳 PatientResponse，status_code=201

## 驗收標準

- `curl http://localhost:8000/patients` 回傳 `[]`
- `curl -X POST http://localhost:8000/patients -H "Content-Type: application/json" -d '{"name":"Alice"}'` 回傳含 id/created_at 的 JSON
- 重複以上操作後 GET /patients 回傳長度大於 0 的陣列

## 實作備註

- 使用 `from fastapi import APIRouter, Depends, HTTPExcepttion`
- 使用 `from sqlmodel import Session, select`
- POST 回傳 HTTP 201：`@router.post("/patients", response_model=PatientResponse, status_code=201)`
- 若 PatientResponse 中多餘欄位（therapist_id 等）在建立時未提供，確保 schema 有正確的預設值
