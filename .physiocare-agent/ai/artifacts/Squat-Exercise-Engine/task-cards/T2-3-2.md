## 目標

在 `SquatEngine` 類別中提供（或確認）`evaluateFrame(landmarks)` 方法，該方法接收原始 landmarks 資料，回傳結構化的 `FormFeedback` 物件，包含即時 form 評估結果、提示語（cues）與角度資訊。

## 情境包（Context Pack）

- 相關檔案：
  - `frontend/src/utils/exerciseEngine.ts` — `SquatEngine` 已實作 `update()` 方法，目前回傳 `ExerciseState`
  - `frontend/src/types/pose.ts` — 已有 `ExerciseState`、`JointAngle`、`ExercisePhase`
  - `frontend/src/utils/angles.ts` — 角度計算函式
- 既有模式：
  - `SquatEngine.update(landmarks)` 已實作完整分析流程
  - 內部使用 `LandmarkSet` 介面（8 個關鍵點）
  - 回傳 `ExerciseState` 含 `formScore`、`dangerScore`、`angles[]`、`isFlagged`、`phase`
  - `evaluateFrame` 可作為 `update()` 的 alias 或包裝
- 假設：
  - `evaluateFrame` 為 `update()` 的同義方法或輕量包裝
  - 輸入格式為 `LandmarkSet`（8 個點的結構化物件）
  - 輸出格式需相容於後續的 `FormFeedback` 型別（見 T2-3-3）
- 未知事項：
  - 是否需要獨立的 `evaluateFrame` 方法，或直接使用 `update()` 即可
  - 是否需要 stateless 評估（不影響引擎內部狀態的唯讀評估）
- 允許變更的檔案：
  - `frontend/src/utils/exerciseEngine.ts`
  - `frontend/src/types/pose.ts` (若需 FormFeedback 型別)
- 不得觸碰：
  - `frontend/src/hooks/`
  - `frontend/src/services/`

## 需求

- `evaluateFrame(landmarks: LandmarkSet): FormFeedback` 方法存在。
- 若作為 `update()` 的 alias，則行為與 `update()` 一致且回傳型別相容。
- 若需要 stateless 版本，則不改變引擎內部 phase/repCount，僅回傳當前 frame 的評估。
- 回傳內容包含：`score`、`jointAngles`、`cues`（string 陣列）。
- 若與 `update()` 功能重疊，應避免重複實作。

## 驗收標準

- 呼叫 `evaluateFrame()` 回傳非 null 的 `FormFeedback` 物件。
- 物件包含 `score: number`（0-100）。
- 物件包含 `cues: string[]`（至少提醒一個姿勢問題或「Good form」）。
- 物件包含 `jointAngles` 陣列（knee、hip、torso 各一筆）。
- `npm run build` 無 type error。

## 實作備註

- 目前 `SquatEngine.update()` 已提供完整功能。若 `evaluateFrame` 定義為 `update` 的 alias，只需新增方法簽章。
- 若需要 stateless 評估，可新增 private helper 方法由 `update()` 與 `evaluateFrame()` 共用。
- `FormFeedback` 型別尚未定義（見 T2-3-3），需協調兩張任務卡的產出。
