## 目標

實作一個純函式 `calculateAngle(a, b, c)`，接受三個 2D 點 (x, y) 並計算以 b 為頂點的角度，回傳值域 0-180 度。這是所有關節角度計算的基礎。

## 情境包（Context Pack）

- 相關檔案：
  - `frontend/src/utils/angles.ts` — 已實作 `calculateAngle()` 及所有特化函式
  - `frontend/src/types/pose.ts` — `Landmark` 型別定義 x, y, z
  - `frontend/src/utils/exerciseEngine.ts` — 消費端
- 既有模式：
  - 使用 `Math.atan2` 進行全 360 度計算
  - 回傳值標準化至 0-180 度
  - 輸入為 `{ x: number, y: number }`（僅使用 2D 投影座標）
- 假設：
  - MediaPipe 回傳的 landmard x, y 為正規化座標（0-1），但計算僅需比值，不影響角度
  - 不考慮 3D z 軸（2D 投影角度即足夠 squat form 分析）
- 未知事項：

## 需求

- `calculateAngle(a, b, c)` 回傳以度為單位的角度（number），值域 [0, 180]。
- 使用 `Math.atan2` 實作以求數值穩定性。
- 當三點共線時應正確回傳 0 或 180。
- 函式為純函式：無 side effect、無相依於外部狀態。
- 輸入型別為 `{ x: number; y: number }`（相容於 `Landmark` 的子集）。

## 驗收標準

- `calculateAngle({x:0,y:0}, {x:0,y:1}, {x:1,y:1})` 回傳 45°。
- `calculateAngle({x:0,y:0}, {x:0,y:0}, {x:1,y:1})` 回傳 0°（頂點重合）。
- `calculateAngle({x:0,y:0}, {x:0,y:1}, {x:0,y:2})` 回傳 0° 或 180°（共線）。
- 所有回傳值在 [0, 180] 區間內。
- `npm run build` 無 type error。
