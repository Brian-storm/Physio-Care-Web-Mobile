## 需求

- 測試 `calculateAngle`：直角 (90°)、45 度、共線 (0°/180°)、頂點重合 (0°)、大鈍角 (>90°)。
- 測試 `calculateKneeAngle`：站直 (180°)、深蹲 (90°)、微彎 (150°)。
- 測試 `calculateHipAngle`：站直 (180°)、深蹲彎腰 (~75°)。
- 測試 `calculateTorsoAngle`：直立 (0°)、前傾 30° (~30°)、前傾 60° (~60°)。
- 測試 `calculateKneeValgus`：正常 (0)、輕微內塌 (>0)、嚴重內塌 (>0.12)。
- 測試案例使用已知幾何輸入並斷言預期輸出值，容許 ±0.5° 浮點誤差。
- 邊界測試：三個點相同位置、極端值（非常大的座標差值）。

## 實作備註

- 使用 `describe` 分組：「calculateAngle」「calculateKneeAngle」「calculateHipAngle」「calculateTorsoAngle」「calculateKneeValgus」。
- 每個群組至少 3 個 `it` 案例。
- 使用 `expect().toBeCloseTo(expected, 1)` 處理浮點誤差。
- 測試框架選擇：若專案無測試框架，建議安裝 Jest + `@types/jest` 並在 `package.json` 加入 `"test": "jest"` script。
