## 需求

- 測試 idle → descending 轉換（5 幀 knee < 120°）。
- 測試 descending → bottom 轉換（5 幀 knee ≤ 90°）。
- 測試 bottom → ascending 轉換（5 幀 knee > 95°）。
- 測試 ascending → completed 轉換（5 幀 knee > 160°，repCount +1）。
- 測試 formScore：完美姿勢 = 100，過度軀幹前傾 = 扣分，膝蓋外翻 = 扣分。
- 測試 dangerScore：嚴重外翻或軀幹過度前傾時危險分數上升。
- 測試 `isFlagged`：dangerScore > 75 時為 true。
- 測試 `reset()`：所有計數器歸零，phase 回到 idle。
- 測試 `getPhase()`：回傳正確的 phase 字串。
- 使用 `describe` 分組：「Phase transitions」「Form scoring」「Danger assessment」「Reset」。
