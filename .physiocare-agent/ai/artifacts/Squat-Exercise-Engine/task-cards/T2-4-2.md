## 目標

在 `SquatEngine` 中實作提示語（cues）的優先排序邏輯，確保每幀輸出的 cue 陣列中最嚴重的問題排在最前面，讓 UI 能優先顯示最重要的矯正提示。同時限制單幀 cue 數量，避免資訊過載。

## 需求

- `update()` 或 `evaluateFrame()` 回傳的 `FormFeedback.cues` 為依優先度排序的 `string[]`。
- 優先度規則：
  1. 最高：dangerScore 相關（膝蓋嚴重外翻 > 0.12、軀幹 > 50°）
  2. 中：form 扣分項目（膝蓋外翻 > 0.08、軀幹 > 40°、深度不足）
  3. 低：提醒（軀幹 > 30° 提醒、膝蓋接近鎖死）
- 同一問題在同一幀只出現一次（不重複）。
- 最多輸出 3 條 cue。
- 若無任何問題則 cues 為空陣列 `[]`（UI 顯示「姿勢良好」由 UI 層處理）。
- 可定義 `CueSeverity` 型別（可選）輔助排序。

## 驗收標準

- 膝蓋嚴重外翻時第一條 cue 為「膝蓋內塌嚴重，請保持膝蓋對齊腳尖」。
- 軀幹過度前傾時第一條 cue 為「軀幹前傾過多，請挺胸」。
- 姿勢完美時 `cues` 為空陣列。
- cue 數量絕不超過 3 條且無重複。
- `npm run build` 無 type error。

## 實作備註

- Cue 文案使用繁體中文。
- 建議實作 `generateCues(angles, dangerScore): string[]` private 方法，依優先規則排序並截斷。
- 優先順序可用 numeric severity score 排序後取 top 3。
- 範例 cue 文案：「膝蓋內塌，請保持膝蓋對齊腳尖」「軀幹前傾過多，請挺胸」「蹲得不夠深，請再往下」「膝蓋超過腳尖，請維持重心在腳跟」。
