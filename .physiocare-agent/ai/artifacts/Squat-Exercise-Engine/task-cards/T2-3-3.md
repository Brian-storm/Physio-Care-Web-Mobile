## 目標

在 `frontend/src/types/pose.ts` 中定義 `FormFeedback` 型別，作為 `SquatEngine` 輸出給 UI 層的標準格式。包含整體評分、逐幀提示語（cues）、各關節角度資料，與 `ExerciseState` 互補。

## 情境包（Context Pack）

- 相關檔案：
  - `frontend/src/types/pose.ts` — 既有型別：`JointAngle`、`ExerciseState`、`ExercisePhase`、`Landmark`
  - `frontend/src/utils/exerciseEngine.ts` — `SquatEngine.update()` 目前回傳 `ExerciseState`
  - `frontend/src/utils/angles.ts` — 角度計算消費端
- 既有模式：
  - `JointAngle` 含 `name`、`value`、`target`、`deviation`、`status`
  - `ExerciseState` 含完整的 session 快照（含 formScore、dangerScore、phase、repCount）
  - 型別使用 `interface` 定義，export 供其他模組使用
- 假設：
  - `FormFeedback` 聚焦於即時單幀回饋，與 `ExerciseState`（session 累積狀態）互補
  - `FormFeedback` 由 UI 層（如 `FormFeedbackPanel` 元件）直接消費
  - `cues` 為字串陣列，依優先順序排列（最重要的 cue 在前）
- 未知事項：
  - 是否需要 `severity` 層級（info/warning/danger）在每個 cue 上
  - 是否需要 `timestamp` 欄位（可從 `ExerciseState` 取得）
- 允許變更的檔案：
  - `frontend/src/types/pose.ts` (新增型別)
- 不得觸碰：
  - `frontend/src/utils/` (僅消費型別，不需變更)
  - `frontend/src/hooks/`

## 需求

- 定義 `FormFeedback` interface，至少包含：
  - `score: number` — 整體 form 評分 (0-100)
  - `cues: string[]` — 提示語陣列（依優先度排序）
  - `jointAngles: JointAngle[]` — 各關節角度
- 可選欄位（依需要加入）：
  - `phase: ExercisePhase`
  - `isFlagged: boolean`
  - `dangerScore: number`
- 型別使用 `export interface FormFeedback { ... }` 語法。
- 檔案頂端加入 `/* PhysioCare — ... */` header。

## 驗收標準

- `FormFeedback` 可被 `SquatEngine.evaluateFrame()` 正確回傳型別。
- `score` 為 `number` 且在 [0, 100] 區間。
- `cues` 為 `string[]`（空陣列表示無需提示）。
- `jointAngles` 為 `JointAngle[]`（至少 knee、hip、torso 三筆）。
- `npm run build` 無 type error。

## 實作備註

- 新增型別後需更新 `exerciseEngine.ts` 中的 `evaluateFrame()` 回傳型別。
- 可考慮 `FormFeedback` 擴充 `ExerciseState` 而非獨立定義（若兩者高度重疊）。
- 若決定讓 `evaluateFrame` 回傳 `ExerciseState`，則 `FormFeedback` 可定義為 `ExerciseState` 的子集或 alias。
