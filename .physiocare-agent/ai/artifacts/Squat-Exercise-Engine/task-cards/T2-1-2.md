## 目標

提供一個 React hook 封裝 `navigator.mediaDevices.getUserMedia()`，處理 webcam 啟動、串流生命週期、錯誤處理，並回傳 `<video>` ref 供後續 pose detection 使用。

  - `frontend/src/hooks/usePose.ts` — 消費端 hook
  - `frontend/src/app/page.tsx` — 預期使用方式
- 既有模式：
  - `useCamera` 回傳 `{ videoRef, isReady, error }` 三值

## 需求

- 啟動 `getUserMedia({ video: { facingMode, width, height }, audio: false })`。
- 將串流綁定至 `videoRef` 並呼叫 `video.play()`。
- `isReady` 在 video 開始播放後設為 `true`。
- 若 camera 權限遭拒，顯示明確中文錯誤訊息：「Camera access denied. Please allow camera permissions.」
- 若 getUserMedia 失敗，顯示通用錯誤訊息。
- Component unmount 時停止所有 track 並釋放串流。
- 可選 `facingMode`、`width`、`height` 參數。

## 驗收標準

- 呼叫 `useCamera()` 後 `videoRef.current` 綁定至 `<video>` 且串流正確顯示。
- `isReady` 在可偵測時為 `true`。
- 拒絕 camera 權限時 `error` 為有意義的錯誤字串。
- Unmount 後瀏覽器 camera 指示燈熄滅。
- 重複 mount/unmount 無記憶體洩漏。
