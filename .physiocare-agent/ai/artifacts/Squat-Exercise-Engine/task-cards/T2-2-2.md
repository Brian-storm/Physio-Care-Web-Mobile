## 目標

在 `calculateAngle` 基礎上建立 squat 專用的角度萃取函式：膝蓋彎曲角 (hip-knee-ankle)、髖彎曲角 (shoulder-hip-knee)、軀幹傾角 (shoulder-hip vs 垂直軸)、膝蓋外翻偵測。

## 需求

- `calculateKneeAngle(hip, knee, ankle)` — 計算膝彎曲角 (180° = 站直, 90° = 深蹲)。
- `calculateHipAngle(shoulder, hip, knee)` — 計算髖彎曲角 (180° = 站直, 越小越彎)。
- `calculateTorsoAngle(shoulder, hip)` — 計算軀幹對垂直軸的傾角 (0° = 直立, 45° = 前傾過多)。
- `calculateKneeValgus(hip, knee, ankle)` — 偵測膝蓋內塌，回傳外翻幅度 (0 = 無, 越大越危險)。
- 所有函式回傳 `number`，valgus 為無單位比例值，角度為度數。

## 驗收標準

- 膝蓋角：站直 = 180°, 深蹲 = 90°。
- 軀幹角：直立 = 0°, 前傾 45° = 45°。
- Valgus：正常蹲姿 = 0, 刻意內塌 > 0。
- 所有函式邊界輸入（重合點、極端值）不拋出錯誤。
- `npm run build` 無 type error。
