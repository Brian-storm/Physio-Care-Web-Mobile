## 目標

建立 `ScoreTrendChart` 元件，使用 Recharts 繪製病人在一段時間內的分數趨勢折線圖，幫助物理治療師評估復健進展。

## 情境包（Context Pack）

- 相關檔案：`frontend/src/components/`、`frontend/package.json`（確認 Recharts 依賴）
- 既有模式：參考 T5-2-1 AngleChart 實作風格
- 假設：分數趨勢資料為 `{ date: string; score: number }[]`
- 未知事項：圖表色彩系統一致性
- 允許變更的檔案：`frontend/src/components/ScoreTrendChart.tsx`
- 不得觸碰：後端

## 需求

- 使用 Recharts `<LineChart>` 繪製分數趨勢
- X 軸顯示日期，Y 軸顯示分數（0-100）
- 顯示數據點與平滑連線
- 包含 tooltip 與圖例
- 支援時間範圍篩選（1 週 / 1 月 / 3 月 / 全部）
- 無資料時顯示「無趨勢資料」

## 驗收標準

- 無資料時顯示提示
