## 目標

建立會話選擇器下拉選單，讓物理治療師在 Session Review 頁面中切換查看該病人的不同會話。

## 情境包（Context Pack）

- 相關檔案：`frontend/src/components/`、`frontend/src/hooks/`
- 既有模式：參考 T5-1-1 PatientSidebar 的下拉選單實作
- 假設：病人會話列表可從 `GET /patients/:id/sessions` 取得
- 未知事項：下拉選單是否需分組（依日期）
- 允許變更的檔案：`frontend/src/components/SessionSelector.tsx`（新建）
- 不得觸碰：AngleChart、FeedbackLog 內部邏輯

## 需求

- 呈現 `<select>` 下拉選單，列出該病人的所有會話
- 每項顯示：日期 + 運動名稱（如「2024-03-15 — Squat」）
- 透過 `onSessionChange(sessionId)` callback 回傳選中會話
- 支援 placeholder 選項

## 驗收標準

- 正確列出所有會話
- 選擇後觸發 callback
- placeholder 不觸發 callback
- 下拉選單樣式與設計系統一致

## 實作備註

- 會話列表應依日期降序排列（最新在上）
- 可與 T5-1-2 SessionHistoryList 共用資料型別
