## 目標

組合 `PatientDetailPage` 頁面，整合 `ScoreTrendChart` 與 `VolumeChart` 元件，顯示特定病人的長期進展資料。

## 情境包（Context Pack）

- 相關檔案：`frontend/src/app/`、`frontend/src/components/ScoreTrendChart.tsx`、`frontend/src/components/VolumeChart.tsx`、`frontend/src/hooks/`
- 既有模式：Next.js App Router、client component、`useParams()`
- 假設：`GET /patients/:id/progress` 回傳分數趨勢與會話量資料
- 未知事項：路由路徑設計
- 允許變更的檔案：`frontend/src/app/patients/[id]/page.tsx`、`frontend/src/hooks/usePatientProgress.ts`
- 不得觸碰：圖表元件內部邏輯

## 需求

- 建立頁面元件，接收 patient ID 作為路由參數
- 建立 `usePatientProgress(patientId)` hook
- 頁面上方：病人基本資訊（姓名、總會話數、平均分數）
- 中間區域：`ScoreTrendChart`
- 下方區域：`VolumeChart`
- 支援 loading（骨架屏）與 error 狀態

## 驗收標準

- 正確根據病人 ID 載入進展資料
- 病人摘要資訊正確顯示
- 兩個圖表成功嵌入並接收正確 props
- loading / error 狀態正確處理
