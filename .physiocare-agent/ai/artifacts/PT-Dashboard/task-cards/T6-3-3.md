## 目標

組合 `SessionReviewPage` 頁面，整合 `SessionSelector`、`AngleChart` 與 `FeedbackLog`，讓物理治療師可以瀏覽與審查特定病人的任何會話。

## 情境包（Context Pack）

- 相關檔案：`frontend/src/app/`、`frontend/src/components/SessionSelector.tsx`、`frontend/src/components/AngleChart.tsx`、`frontend/src/components/FeedbackLog.tsx`、`frontend/src/hooks/`
- 既有模式：參考 T5-2-3 SessionDetailPage 佈局
- 假設：路由為 `/patients/[id]/sessions`；`GET /sessions/:id` 回傳完整會話
- 未知事項：頁面是否需要返回按鈕
- 允許變更的檔案：`frontend/src/app/patients/[id]/sessions/page.tsx`（新建）
- 不得觸碰：所有子元件內部邏輯

## 需求

- 建立頁面，接收 patient ID 作為路由參數
- 建立 `useSessionsList(patientId)` 取得會話列表供 `SessionSelector` 使用
- 上方區域：`SessionSelector` 選擇會話
- 中間區域：`AngleChart` 顯示所選會話的角度資料
- 下方區域：`FeedbackLog` 顯示所選會話的回饋記錄
- 支援 loading 與 error 狀態

## 驗收標準

- 正確根據 patient ID 載入會話列表
- 選擇會話後，AngleChart 與 FeedbackLog 正確更新
- 切換會話時資料正確刷新
- loading / error 狀態正確處理

## 實作備註

- `"use client"` 標記
- 選擇會話後自動捲動至圖表區域
