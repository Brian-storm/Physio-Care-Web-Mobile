## 目標

建立一個側邊欄下拉選單元件 `PatientSidebar`，讓使用者可以選擇病人，並觸發該病人的會話歷史資料查詢。

## 情境包（Context Pack）

- 相關檔案：`frontend/src/components/`（既有元件目錄）、`frontend/src/app/`（頁面目錄）
- 既有模式：PascalCase 元件命名、`@/` path alias、TailwindCSS 樣式
- 假設：病人資料可從 GET /patients 取得；選單變更時會透過 callback 通知父層
- 未知事項：目前是否已有 Patient 型別定義 — 需確認 `frontend/src/types/` 下是否存在
- 允許變更的檔案：`frontend/src/components/PatientSidebar.tsx`
- 不得觸碰：後端 API、資料庫模型

## 需求

- 呈現 `<select>` 下拉選單，列出所有病人姓名
- 支援 placeholder 選項（如「選擇病人…」）
- 透過 `onPatientChange(patientId: string)` callback 回傳選中的 patientId
- 當 `patientId` 為空時顯示 placeholder
- 使用 TailwindCSS 樣式，與現有設計系統一致

## 驗收標準

- 下拉選單正確渲染病人列表
- 選擇病人後觸發 callback 並傳入正確的 patientId
- placeholder 選項不會觸發 callback
- 元件在無資料時顯示空狀態提示

## 實作備註

- 可先用靜態 mock 資料，後續接真實 API
- 與 T5-1-3 的 fetch hook 搭配使用
