## 目標

建立 `SessionHistoryList` 表格元件，以表格形式呈現病人的會話歷史記錄，包含日期、運動名稱、分數與持續時間。

## 情境包（Context Pack）

- 相關檔案：`frontend/src/components/`、`frontend/src/types/`
- 既有模式：TailwindCSS 表格樣式、PascalCase 元件
- 假設：session 資料符合 `{ id, date, exerciseName, score, duration }` 格式
- 未知事項：Session 型別欄位名稱需與後端 API 回應一致
- 允許變更的檔案：`frontend/src/components/SessionHistoryList.tsx`
- 不得觸碰：後端 API、資料庫模型

## 需求

- 渲染一個響應式表格，欄位包含：日期、運動名稱、分數、持續時間
- 支援「無資料」空狀態顯示
- 分數以百分比或數值顯示，持續時間以「分：秒」格式顯示
- 每列可點擊（透過 `onSessionClick(sessionId)` callback），導向會話詳情
- 使用 TailwindCSS 美化表格樣式（斑馬紋、懸停效果）

## 驗收標準

- 正確渲染所有 session 資料列
- 空狀態時顯示「尚無會話記錄」提示
- 點擊列觸發 callback 並傳入正確 sessionId
- 日期格式顯示為 YYYY-MM-DD
- 持續時間格式正確

## 實作備註

- 表格應有最小高度，避免 layout shift
- hover 時 row 有背景色變化
