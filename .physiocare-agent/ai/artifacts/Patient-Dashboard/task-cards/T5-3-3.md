## 目標

建立 `useExercises` hook 從 `GET /exercises` 擷取運動庫資料，並注入 `ExerciseLibraryGrid` 元件中。

## 情境包（Context Pack）

- 相關檔案：`frontend/src/hooks/`、`frontend/src/services/`、`frontend/src/components/ExerciseLibraryGrid.tsx`
- 既有模式：`use` prefix hook、`@/services/` API 呼叫
- 假設：`GET /exercises` 已實作，回應格式為 `{ exercises: Exercise[] }`

- 不得觸碰：`ExerciseLibraryGrid` 與 `ExerciseCard` 內部邏輯

## 需求

- 建立 `useExercises()` hook
- 元件掛載時自動發送請求
- 支援 loading、error、data 三種狀態
- 將資料傳遞給 `ExerciseLibraryGrid`
