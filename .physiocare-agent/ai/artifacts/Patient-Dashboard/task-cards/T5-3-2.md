## 目標

建立 `ExerciseLibraryGrid` 網格元件，以響應式網格佈局呈現 `ExerciseCard` 列表，並支援依目標部位篩選與搜尋。

## 情境包（Context Pack）

- 相關檔案：`frontend/src/components/ExerciseCard.tsx`、`frontend/src/components/`
- 既有模式：TailwindCSS grid、filter 邏輯
- 假設：運動資料陣列作為 props 傳入
- 未知事項：篩選器 UI 風格
- 允許變更的檔案：`frontend/src/components/ExerciseLibraryGrid.tsx`
- 不得觸碰：`ExerciseCard` 內部邏輯

## 需求

- 使用 CSS Grid 響應式佈局（mobile: 1 列, tablet: 2 列, desktop: 3-4 列）
- 嵌入 `ExerciseCard` 渲染每個運動
- 支援依目標部位篩選（dropdown 或多選按鈕）
- 支援關鍵字搜尋（運動名稱）
- 空篩選結果時顯示「無符合運動」
- 載入中顯示 skeleton grid

## 驗收標準

- 網格正確響應不同螢幕寬度
- 篩選與搜尋功能正確過濾運動
- 無結果時顯示空狀態
- 點擊卡片傳遞正確 exerciseId

## 實作備註

- 篩選與搜尋邏輯在 client 端進行（資料量小）
- 考慮加入「全部」選項重置篩選
