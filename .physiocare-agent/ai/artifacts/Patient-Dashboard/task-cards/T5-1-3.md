## 目標

建立 `useSessions` hook，從 `GET /sessions?patient_id=X` 擷取會話資料，並將資料注入 `SessionHistoryList` 元件。

## 情境包（Context Pack）

- 相關檔案：`frontend/src/hooks/`（既有 hooks 目錄）、`frontend/src/services/`（API 服務層）、`frontend/src/components/SessionHistoryList.tsx`
- 既有模式：`use` prefix hook 命名、`@/services/` API 呼叫
- 假設：後端已實作 `GET /sessions` endpoint；回應格式為 `{ sessions: Session[] }`
- 未知事項：後端 API 的認證方式
- 允許變更的檔案：`frontend/src/hooks/useSessions.ts`、`frontend/src/services/sessionService.ts`（如需）
- 不得觸碰：後端、資料庫模型、`SessionHistoryList` 元件邏輯

## 需求

- 建立 `useSessions(patientId: string | null)` hook
- 當 `patientId` 變更時自動發送請求
- 支援 loading、error、data 三種狀態
- 將資料傳遞給 `SessionHistoryList` 進行渲染
- 與 T5-1-1 的 PatientSidebar 整合：選擇病人後自動載入該病人會話

## 驗收標準

- 正確發送 `GET /sessions?patient_id={id}` 請求
- 成功時將資料傳入 `SessionHistoryList`
- 切換病人時正確更新資料
- loading 狀態顯示載入中提示
- error 狀態顯示錯誤訊息

## 實作備註

- 使用 `useEffect` 或 React Query 處理非同步請求
- 考慮加入防抖（debounce）或取消請求機制
