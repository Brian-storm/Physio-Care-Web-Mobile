## 目標

組合 `SessionDetailPage` 頁面，整合 `AngleChart` 與 `FeedbackLog` 元件，並從 API 取得單一會話的完整詳情資料。

## 情境包（Context Pack）

- 相關檔案：`frontend/src/app/`（頁面目錄）、`frontend/src/components/AngleChart.tsx`、`frontend/src/components/FeedbackLog.tsx`、`frontend/src/hooks/`、`frontend/src/services/`
- 既有模式：Next.js App Router page 結構、`@/components/` 引用
- 假設：`GET /sessions/:id` 回傳包含角度資料與回饋列表的完整會話物件
- 未知事項：路由設計（`/patient/sessions/:id` 或 `/sessions/:id`）
- 允許變更的檔案：`frontend/src/app/sessions/[id]/page.tsx`、`frontend/src/hooks/useSessionDetail.ts`
- 不得觸碰：`AngleChart`、`FeedbackLog` 元件內部邏輯

## 需求

- 建立頁面元件，接收 session ID 作為路由參數
- 建立 `useSessionDetail(sessionId)` hook 取得會話資料
- 上方區域顯示會話摘要（日期、運動名稱、總分數、持續時間）
- 中間區域嵌入 `AngleChart`
- 下方區域嵌入 `FeedbackLog`
- 支援 loading 狀態（骨架屏）與 error 狀態

## 驗收標準

- 正確根據 session ID 載入資料
- 會話摘要資訊正確顯示
- `AngleChart` 與 `FeedbackLog` 成功嵌入並接收正確 props
- loading 時顯示骨架屏
- error 時顯示錯誤訊息與重試按鈕

## 實作備註

- 頁面為 client component（`"use client"`）
- 從 `useParams()` 取得 session ID
